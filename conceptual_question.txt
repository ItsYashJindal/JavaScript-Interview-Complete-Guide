5. Which runs first: Promise or setTimeout?
👉 Promise runs first because it goes to the Microtask Queue, which has higher priority than the Callback Queue.

6. Is the Event Loop multi-threading?
👉 No. JavaScript is single-threaded. The Event Loop only manages asynchronous tasks.

7. async/await belongs to which queue?
👉 Microtask Queue, because async/await is based on Promises.

8. Why does Microtask Queue have higher priority?
👉 To complete Promise-related tasks first and keep data consistent.

9. When does the Event Loop run?
👉 When the Call Stack becomes empty.

10. Why is Call Stack important?
👉 It executes synchronous JavaScript code line by line.

11. Which queue do DOM events go to?
👉 Callback (Macrotask) Queue.

12. Does setTimeout(0) execute immediately?
👉 No. It runs only after the Call Stack is empty and microtasks are completed.
